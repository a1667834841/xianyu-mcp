# 闲鱼近期爆款商品与关键词分析

## Overview

用真实闲鱼搜索结果分析某个商品类目方向，找出近期火爆商品链接，并从标题和描述中提炼热词、关键词、长尾词，用于重新编辑商品标题和描述以提升曝光度与流量。

核心原则：先拿真实竞品数据，再总结词；不要凭常识编造热词、链接或爆款规律。

## When To Use

- 用户要分析某个闲鱼类目、商品方向、竞品、近期火爆商品。
- 用户要找商品链接、热词、标题关键词、描述关键词、长尾词。
- 用户要根据竞品词库重写标题、描述、卖点，提高曝光、搜索流量、点击率。

## Required Data Flow

1. 明确类目方向：记录用户给出的品类、品牌、型号、用途、价格带或目标人群。
2. 扩展搜索词：从核心品类扩展 3-6 个同义词、场景词、品牌词或规格词。
3. 调用 `xianyu_search`：每个关键词搜索 30-100 条，优先保留近 30 天或发布时间较近的结果。
4. 本地筛选：按 `exposure_score` 降序，结合 `want_cnt`、发布时间、价格、标题相关性取 TOP 5-10。
5. 调用 `xianyu_get_detail`：逐个获取 TOP 商品详情，必须读取标题、描述、价格、发布时间和链接。
6. 抽词：从标题提炼热词，从描述提炼关键词、卖点词、痛点词、信任词、长尾词。
7. 输出可复用词库：说明哪些词适合标题，哪些词适合正文，哪些词适合标签或图片文案。
8. 给出改写建议：只基于用户商品真实信息和竞品词库重写，不编造品牌、成色、授权、库存、发货承诺或功效。

## Ranking Rules

优先级：近期 + 高曝光 + 高想要 + 强相关。

| 指标 | 用法 |
| --- | --- |
| `exposure_score` | 第一排序，越高越像近期火爆商品 |
| `want_cnt` | 辅助判断需求强度 |
| `publish_time` | 排除过旧商品，优先近期样本 |
| `price` | 总结主流价格带和低价锚点 |
| `title` / `description` | 提取可复用关键词和长尾词 |

## Keyword Extraction Rules

| 词类 | 从哪里找 | 示例 |
| --- | --- | --- |
| 热词 | TOP 商品标题高频词 | 全新、现货、包邮、清仓、正品 |
| 描述关键词 | 描述中反复出现的卖点 | 自用闲置、未拆封、盒卡齐全、支持验货 |
| 长尾词 | 买家会搜索的自然短语 | 送礼用泡泡玛特挂件、宝宝可啃咬爬行垫 |
| 痛点词 | 解决顾虑的表达 | 无味道、不红屁屁、防伪可查、实拍细节 |
| 转化词 | 促成点击或咨询的表达 | 急出、最后几件、同城可自提、可小刀 |

## Example

```text
用户类目：泡泡玛特礼物

近期火爆商品链接：
1. 星星人挂件 ... https://www.goofish.com/item?id=xxx 曝光度 8120 想要 96

热词：泡泡玛特、星星人、挂件、礼物、全新未拆、盒卡齐全、现货、包邮、送礼

描述关键词：官方正品、防伪码、实拍、毛绒手感、挂包、钥匙扣、生日礼物

长尾词：泡泡玛特生日礼物、星星人毛绒挂件、送女生小礼物、全新未拆盲盒挂件

改写方向：标题放“泡泡玛特 + 具体系列 + 礼物/挂件”；正文自然植入“全新未拆、盒卡齐全、送礼、实拍、防伪码”。
```

## Red Flags

- 只输出通用营销建议，没有真实商品链接。
- 没有调用 `xianyu_get_detail` 就总结描述关键词。
- 把搜索关键词当成最终热词，没有从 TOP 商品中验证。
- 只堆关键词，未说明如何自然改写标题和描述。
- 编造商品详情中不存在的品牌、成色、授权、功效或发货承诺。

## Common Rationalizations

| 借口 | 修正 |
| --- | --- |
| “先给框架就行” | 用户要近期火爆链接和词库，必须基于真实搜索结果 |
| “标题够用了，不用详情” | 长尾词主要来自描述，必须读取详情 |
| “曝光高就一定可抄” | 只提取结构和词，不复制原文 |
| “热词越多越好” | 词要分类，并说明适合标题、正文还是标签 |

## Common Mistakes

| 误区 | 修正 |
| --- | --- |
| 默认先排查登录 | 先搜索；只有工具报会话错误再检查登录 |
| 忽略发布时间 | 近期火爆必须结合 `publish_time` 和 `exposure_score` |
| 只看一个关键词 | 扩展同义词、场景词、品牌词交叉验证 |
| 把竞品描述照搬 | 提取关键词和结构，重新表达 |
| 输出无法复用 | 必须给标题词、正文词、长尾词和改写建议 |
